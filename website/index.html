Capabilities

Everything you need to
trust the clock.

The client is never trusted. Every punch is validated server-side against the worker's GPS, a defined workplace boundary, and their device.

Polygon Geofencing

Not just a radius. Define exact work areas using complex polygons on satellite imagery. Server-side ray-casting ensures workers are exactly inside the boundary.

Server-Side Face Check

Client-side spoofing is blocked. We downscale and hash the photo on the server, comparing it to the enrolled template. Raw images are never persisted.

Device Binding

Tie a worker to a specific phone. A SHA-256 device fingerprint is captured on login. If a different phone tries to use the account, check-in is blocked.

GPS Sanity Check

Impossible travel? We calculate the speed between punches. If it's over 180 km/h, the check-in is blocked and an anomaly alert is triggered.

Payroll Ready

Export daily, monthly, or custom date ranges to CSV or Excel. Overtime, breaks, and missed checkouts are automatically calculated.

Multi-Tenant Architecture

One backend, three consoles. Geo-Lo owners manage organizations, Org Admins manage workers, and Workers track their time.

How it works

The worker check-in flow

From the moment they arrive, the client is validated securely against the server.

1

Authenticate

Worker signs in with their email and secure PIN. A token is issued and device fingerprint captured.

2

Capture GPS

Browser captures a high-accuracy location fix and takes a photo for face verification.

3

Validate

Server checks device binding, GPS sanity, face hash, and runs the point-in-polygon test.

✓

Record

If all checks pass, the attendance is logged. If not, it's blocked and audited.

Trust & Safety

Built on the principle of
zero trust.

We don't rely on the client to tell the truth. Every operational row carries an organization_id, preventing cross-tenant data leaks. Passwords use bcrypt, while session tokens are hashed with SHA-256.

  • Multi-tenant isolation by default
  • Prepared SQL statements everywhere
  • Full immutable audit logging
  • Role-based access control (RBAC)
